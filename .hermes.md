# aoi project instructions — loaded in every session inside this folder

## What the project is
A moment-by-moment data collection system for the fomo.family trading platform (no official API — Cloudflare is bypassed via curl_cffi).
It labels the outcome of every signal after 48 hours and builds training rows for a model that predicts which coin will rise after a buy signal.

## Strict rules (never violated)
1. **The `recorder/recorder.db` database is read-only for the agent** (`mode=ro`). No direct INSERT/UPDATE/DDL ever — writes go exclusively through the services.
2. **Never kill or reschedule the Windows scheduled tasks** (the services run under pythonw.exe with no windows and survive reboots). If one looks stopped, diagnose the cause from the logs first.
3. **Secrets stay out of bounds**: `chain_keys.json`, `api/.env`, `api/.privy_state.json*` — never read their contents or copy them into outputs or reports.
4. **The phase-1 gate is binding**: control-v3 mature count at **426/500** (snapshot 2026-08-29; the live number is at `/api/labeling`). **No approved entry-model training** before reaching 500. The exploratory threshold (100) is open.
5. Every change ends with green tests (`./run_tests.ps1` or `py -3 -m pytest recorder/tests/...`) before any commit.

## Architecture (permanent services + two periodic tasks)
| Service | Cadence | Role |
|---|---|---|
| FomoApiServer :8080 | permanent | fomo.family gateway + self-renewing Privy auth |
| FomoRecorder | every 60 s | capture the decision moment t=0 |
| FomoChain | every 60 s | Solana contracts (Helius/official RPC) |
| FomoEVMReplay | every 60 s | EVM behavior replay |
| FomoLabeler | every 15 min | label outcomes after 48 hours |
| FomoBuildRows | hourly | build training rows |
| FomoActivityHead | every 5 min | plug the tradingActivity head with the rotating token |
| FomoDashboard :8090 | permanent | read-only display |
| FomoBars1m | hourly | archive one-minute candles |
| FomoBackup | daily 03:15 | backup to OneDrive |
